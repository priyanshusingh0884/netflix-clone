# Netflix India Landing Page Clone 🎬

A frontend clone of the Netflix India landing page, built using HTML5 and CSS3. The project recreates the visual layout and design of Netflix's landing page with responsive styling.

## ✨ Features

- Netflix-inspired navigation bar.
- Hero section with background image and membership form.
- Watch on TV section with video preview.
- Download shows section.
- Watch everywhere section.
- Kids profile section.
- Frequently Asked Questions section.
- Footer with multiple navigation links.
- Responsive layout using CSS media queries.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
- Flexbox
- CSS Grid
- Media Queries

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/netflix-clone.git
```

2. Open the project folder.
3. Open `index.html` in your browser.

## 📌 Note

This project is a frontend practice clone created for educational purposes. It does not provide actual Netflix streaming, authentication, or membership functionality.
